🧬 Analisador de Complementaridade e Composição de Primers

Este projeto é um script em Python que calcula a complementaridade entre primers, bem como a proporção de bases A/T e G/C em cada sequência.
É uma ferramenta simples, mas poderosa, para análise inicial de oligonucleotídeos em projetos de biologia molecular e bioinformática.

⚗️ Ideal para verificar possíveis auto-complementaridades, complementaridade cruzada e equilíbrio entre bases antes de desenhar primers.

🚀 Funcionalidades

Cálculo da complementaridade

Avalia o quanto um primer é complementar a si mesmo (auto-complementaridade).

Avalia a complementaridade entre primer forward e reverse.

Composição de bases

Calcula os percentuais de A/T e G/C em cada primer.

Útil para avaliar estabilidade térmica e qualidade dos primers.

Interpretação simples e direta

Interface via terminal.

Retorna resultados formatados com duas casas decimais.
